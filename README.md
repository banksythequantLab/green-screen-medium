# Green Screen Medium

Turn legacy terminal screens (IBM 3270 mainframe, AS/400 5250) into MCP tools
and REST endpoints, without changing a line of code on the host.

Walk through a transaction once in a web terminal. Green Screen Medium records
it, names the inputs and outputs, and publishes it as a typed tool that any AI
agent or modern app can call.

Built with [Kiro](https://kiro.dev) for the Kiroween 2026 hackathon
(Resurrection category). See `/.kiro` for the specs, steering and hooks.
